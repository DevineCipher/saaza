# Saaza.pk

React replica of the [Saaza.pk Odoo store](https://saazapk2.odoo.com/), with the original product photos, copy, and layout.

## Local preview

```bash
npm install
npm run dev
```

## GitHub Pages

This repo deploys from `main` through GitHub Actions. After the first push:

1. Open the repository on GitHub
2. Go to **Settings → Pages**
3. Set **Source** to **GitHub Actions**

The live site will be at `https://<your-username>.github.io/saaza/`.
