# Saaza.pk

React replica of the [Saaza.pk Odoo store](https://saazapk2.odoo.com/), with the original product photos, copy, and layout.

## Local preview

```bash
npm install
npm run dev
```

## GitHub Pages

After pushing to GitHub, the site is published from the `gh-pages` branch at `https://<your-username>.github.io/saaza/`.
